演習21 アニメーション・クロスフェード アーキテクチャ設計図

本ページは、DirectX11エンジンにおける AnimatorComponent 集約型クロスフェードの設計を Mermaid.js によりグラフィカルにレンダリングしたものです。

2. 毎フレームの実行シーケンス図（Sequence Diagram）

sequenceDiagram
    autonumber
    actor App as App (ゲームループ)
    participant AnimatorSys as AnimatorSystem::Update
    participant AnimatorComp as AnimatorComponent
    participant AnimSys as AnimationSystem::Update
    participant AnimComp as AnimationComponent
    participant SkelComp as SkeletonComponent (ボーン配列)

    Note over App, AnimatorComp: 1. 遷移トリガー (任意のタイミング)
    App->>AnimatorSys: CrossFade(registry, entity, "Walk", 0.25f)
    Note over AnimatorComp: pPrevClip ← 現在クリップ
pCurrentClip ← Walkクリップ
timer = 0.0f, isTransitioning = true

    Note over App, SkelComp: 2. 毎フレームの定期更新ループ (Update)
    App->>AnimatorSys: Update(registry, dt)
    opt isTransitioning == true
        AnimatorSys->>AnimatorComp: タイマー進行 (timer += dt)
        AnimatorSys->>AnimatorComp: 遷移ウェイト算出 (weight = timer / duration)
        opt timer >= duration (遷移完了時)
            AnimatorSys->>AnimatorComp: isTransitioning = false, pPrevClip = nullptr
        end
    end

    App->>AnimSys: Update(registry, dt)
    AnimSys->>AnimComp: 現在の再生時刻を進める (currentTime += dt)
    AnimSys->>AnimatorComp: try_get で遷移状態 (weight, pPrevClip) を取得
    
    alt isTransitioning == true (クロスフェード中)
        Note over AnimSys: Prev と Current の2つから姿勢をサンプリング
        Note over AnimSys: Slerp / Lerp でウェイト合成
    else isTransitioning == false (単一通常再生)
        Note over AnimSys: Current のみから姿勢をサンプリング
    end

    AnimSys->>SkelComp: 合成後の行列を Bone.LocalTransformMatrix に書き込み

3. コンポーネント構造と関連図（Class Diagram）

classDiagram
    class AnimatorComponent {
        +unordered_map~string, AnimationState2~ stateMap
        +string currentStateName
        +string prevStateName
        +shared_ptr~AnimationClip~ pPrevClip
        +float prevTime
        +float transitionDuration
        +float transitionTimer
        +float transitionWeight
        +bool isTransitioning
        +AddState(string stateName, shared_ptr~AnimationClip~ pClip, bool isLoop) void
    }

    class AnimationComponent {
        +shared_ptr~AnimationClip~ pCurrentClip
        +float currentTime
        +float playbackSpeed
        +bool isLoop
        +bool isPlaying
    }

    class SkeletonComponent {
        +vector~Bone~ bones
        +int rootBoneIndex
    }

    class BoneTransformTRS {
        +XMVECTOR scale
        +XMVECTOR rot
        +XMVECTOR pos
    }

    class AnimatorSystem {
        +Update(registry, dt) void
        +Play(registry, entity, stateName) void
        +CrossFade(registry, entity, stateName, duration) void
    }

    class AnimationSystem {
        +Update(registry, dt) void
        +SampleBoneTransform(clip, time, bone) BoneTransformTRS
    }

    AnimatorSystem ..> AnimatorComponent : 遷移タイマー進行と完了管理
    AnimationSystem ..> AnimationComponent : 基本再生時刻の更新
    AnimationSystem ..> AnimatorComponent : 遷移ウェイトと前クリップの読み取り (Optional)
    AnimationSystem ..> SkeletonComponent : Bone.LocalTransformMatrix を更新
    AnimationSystem ..> BoneTransformTRS : サンプリング中間データの生成
